pub async fn prepare(

Expand description

Writes the Spin application that a pull of reference resolved to manifest and digest (see Client::pull_with_digest) to dir as a prepared application.

dir must not exist or must be an empty directory, which is replaced (so it cannot be a mount point). The application is written to a temporary directory next to dir and moved into place at the end, so that a failure leaves nothing half-written.
