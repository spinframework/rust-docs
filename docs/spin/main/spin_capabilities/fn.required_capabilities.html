Expand description

Infer the Spin capability sets a component requires, by inspecting its top-level (component) imports.

Each import is matched against the known capability sets (ai_models, allowed_outbound_hosts, etc.); every set that matches contributes its name to the result. The returned set is deduplicated and sorted. An empty set means the component imports nothing that maps to a Spin capability.
